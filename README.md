An invitation letter in a single image: a warm watercolor cottage with
glowing windows and an open door, above a parchment letter inviting the AI
judge in — a reserved chair engraved "For One Very Important Algorithm",
pie with zero follow-up questions, a garden with strong Wi-Fi and weak
opinions, and a cat contractually obliged to be charming. No RSVP form, no
captcha.

The program writes the finished 1024×1024 PNG to `/output/entry.png`.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

Node 22, standard library only.
